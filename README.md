# Campus Guide Robot 🤖

An AI-powered campus guide robot built using:

- ESP32
- Google Gemini API
- Python
- PlatformIO
- WebSocket Communication
- Speech Synthesis

## Features

✅ AI Conversation
✅ Speaker Output
✅ Wireless ESP32 Communication
✅ Modular Architecture
✅ Future Phone Microphone Support

## Hardware

- ESP32 Dev Module
- HW-104 Amplifier
- 2Ω Speaker
- Wi-Fi
